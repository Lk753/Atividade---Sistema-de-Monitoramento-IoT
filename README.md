# Atividade---Sistema-de-Monitoramento-IoT
## Objetivo Principal
O objetivo foi do projeto foi desenvolver um banco de dados utilizando o MySQL como base.
Para fazer isso utilizamos os comandos: 
#### CREATE DATABASE pimpolho - para que seja possivel criar um banco de dados próprio para colocar as tabelas que serão utilizadas no projeto, pimpolho é o nome do banco de dados.
#### USE pimpolho - para indicar que será utilizado o banco de dados selecionado, para criar tabelas e o restante da programação
#### CREATE TABLE - cria as tabelas e as colunas
